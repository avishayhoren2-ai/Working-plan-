# 🔥 FlameFit — אימוני HIIT לשריפת שומן (בטוח לברך)

אפליקציית **PWA** (Progressive Web App) לאימוני אינטרוולים בעצימות גבוהה (HIIT)
לשריפת שומן — מותאמת אישית ל**גבר בן 47, 100 ק"ג, עם קרע ברצועות הברך**.

> ✅ **כל התרגילים בטוחים לברך:** ללא ריצה, ללא קפיצות, ללא ברפיז, ללא לאנג'ים/סקוואט עמוקים וללא סיבובי ברך.

## ✨ מה יש באפליקציה
- **5 אימוני HIIT** מוכנים: פלג עליון 💪, מטבולי 🔥, ליבה 🎯, גוף מלא ⚡, התאוששות 🌿
- **טיימר אינטרוולים מסך-מלא** עם טבעת התקדמות, צלילי ספירה לאחור ורטט
- חימום → סבבים (עבודה/מנוחה) → שחרור — אוטומטי לכל אימון
- **תכנית שבועית** של 6 ימים + יום מנוחה
- מעקב התקדמות: רצף ימים 🔥, אימוני השבוע, סה״כ — נשמר במכשיר (localStorage)
- הסבר + "נקודות מפתח" (cues) לכל תרגיל, עם הדגשת בטיחות לברך
- עיצוב מודרני כהה בצבעי פיטנס (ליים/ציאן/כתום), מותאם RTL ולמובייל
- עובד **גם בלי אינטרנט** (Service Worker) וניתן **להוספה למסך הבית**

## 📲 התקנה למסך הבית
**אנדרואיד (Chrome):** פותחים את הקישור ← לוחצים על כפתור **"⬇️ התקן"** למעלה, או תפריט ⋮ ← "הוספה למסך הבית".
**אייפון (Safari):** כפתור שיתוף ⬆️ ← "הוסף למסך הבית".
לאחר ההתקנה האפליקציה נפתחת במסך מלא כמו אפליקציה רגילה.

## 🚀 העלאה לאוויר (חינם)
זהו אתר סטטי (ללא שרת/בנייה). אפשר לארח חינם:
- **Vercel / Netlify:** מחברים את ה-Repository ולוחצים Deploy (אין צורך בהגדרות build).
- **GitHub Pages:** Settings → Pages → בוחרים Branch → Save.

> חשוב ל-PWA: יש לארח ב-**HTTPS** (Vercel/Netlify/GitHub Pages מספקים זאת אוטומטית).

## 🗂️ מבנה הקבצים
```
index.html                 # מבנה האפליקציה
manifest.webmanifest       # הגדרות PWA (התקנה למסך הבית)
sw.js                      # Service Worker (עבודה לא-מקוונת)
assets/css/style.css       # עיצוב
assets/js/data.js          # התכנית: בנק תרגילים, אימונים, שבוע, טיפים
assets/js/app.js           # לוגיקה + מנוע הטיימר
assets/icons/              # אייקונים של האפליקציה
```

## ✏️ עריכת התכנית
כל התרגילים והאימונים נמצאים ב-`assets/js/data.js` — קל לערוך זמני עבודה/מנוחה,
מספר סבבים, להוסיף תרגילים או לשנות את התכנית השבועית.

## ⚠️ הבהרה רפואית
התכנית מותאמת לעומס נמוך על הברך אך **אינה תחליף לייעוץ רפואי**.
בשל הקרע ברצועות הברך — מומלץ לקבל אישור מרופא אורתופד/פיזיותרפיסט לפני תחילת האימונים,
ולעצור מיד בכל כאב חד או נפיחות.
