# אתר הורנשטיין — סיטונאות ושיווק מוצרי מזון

אתר תדמית סטטי (HTML/CSS/JS) עבור **שיווק למוצרי מזון הורנשטיין בע״מ**.
האתר שייך לכם במלואו, ללא תלות בספק חיצוני, וניתן לארח אותו בחינם.

## קבצים
- `index.html` — תוכן האתר (כל הטקסטים והסקשנים)
- `styles.css` — העיצוב
- `script.js` — תפריט נייד + שנה בפוטר
- אין צורך בשרת או בבנייה — זה אתר סטטי שרץ מכל מקום.

## איך לצפות באתר במחשב
פותחים את `index.html` בדפדפן (דאבל קליק) — זהו.

## איך לפרסם את האתר באוויר (חינם)
אפשרויות מומלצות, כולן מאפשרות לחבר את הדומיין `horenshtine.co.il`:
- **Vercel** — מתחברים עם חשבון GitHub, בוחרים את הריפו, Deploy.
- **Netlify** — גוררים את התיקייה לאתר netlify.com/drop.
- **GitHub Pages** — Settings → Pages → Branch.

## חיבור הדומיין הקיים (השתחררות מאינדקס מדיה)
הדומיין `horenshtine.co.il` רשום ב־ISOC-IL. צריך:
1. לוודא שאתם בעלי הרישום (Registrant) — ולא חברת אינדקס מדיה.
2. אם הם הרשמים — לבקש העברת בעלות / שינוי רשם.
3. לאחר שיש לכם גישה, מעדכנים את רשומות ה־DNS שיצביעו על השירות החדש.

## עריכת תוכן
כל הטקסטים נמצאים ב־`index.html` בעברית — אפשר לערוך ישירות.
טלפון, אימייל וכתובת מופיעים במספר מקומות (header, hero, contact, footer).
