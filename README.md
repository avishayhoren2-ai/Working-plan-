# אתר הורנשטיין – סיטונאות ושיווק מוצרי מזון

אתר תדמית מודרני, מהיר ורספונסיבי (מותאם לנייד) עבור **הורנשטיין**.
האתר בנוי כ-HTML/CSS/JS סטטי בלבד — בלי שרת ובלי עלויות — וניתן לארח אותו **בחינם**.

## מבנה הקבצים
```
index.html           # הדף הראשי (כל התוכן)
assets/css/style.css # עיצוב
assets/js/main.js    # תפריט נייד והתנהגות
```

## איך מעלים את האתר לאוויר (בחינם)

### אפשרות 1 – GitHub Pages (חינם לגמרי)
1. בהגדרות ה-Repository בגיטהאב: **Settings → Pages**.
2. תחת *Source* בחרו את הענף (Branch) ולחצו **Save**.
3. תוך דקה האתר יעלה בכתובת `https://<user>.github.io/<repo>/`.

### אפשרות 2 – Vercel / Netlify (חינם, כולל דומיין)
1. נכנסים ל-Vercel/Netlify ומחברים את ה-Repository.
2. ללא הגדרות build — זה אתר סטטי, פשוט "Deploy".

## חיבור הדומיין הקיים (horenshtine.co.il)
כדי לשמור על אותה כתובת אתר ולחסוך את העלות לאינטגרל:
1. בעמוד ניהול הדומיין (אצל רשם הדומיין), מפנים את ה-DNS ל-GitHub Pages או ל-Vercel.
2. ב-GitHub Pages מוסיפים את הדומיין תחת **Settings → Pages → Custom domain**.

## טופס "צור קשר"
הטופס מוכן לחיבור לשירות חינמי **Formspree**:
1. נרשמים ב-https://formspree.io (חינם).
2. מעתיקים את ה-Form ID ומחליפים ב-`index.html` את `your-id` בשורת ה-`action`.
3. מאותו רגע כל פנייה תגיע ישירות למייל.

## עריכת תוכן
כל הטקסטים נמצאים ב-`index.html` וניתן לערוך אותם בקלות.
פרטי הקשר (טלפון/מייל/כתובת) מופיעים גם בקטע "צור קשר" וגם ב-Footer.
